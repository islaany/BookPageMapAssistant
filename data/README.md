# 数据文件夹 (data/)

本目录存放「书页笔记地图助手」的**外部参考数据**，来源是夸克网盘分享：

- 夸克分享链接：https://pan.quark.cn/s/72ff34627b01

## 用途
- 第二阶段（截图匹配 + 地图定位）所需的参考地图、素材等。
- 第一阶段只验证悬浮覆盖能力，**不需要**这里的文件，覆盖层用的是 `app/src/main/res/drawable/map_overlay.png` 占位图。

## 管理约定
- 把夸克网盘里的数据下载 / 解压进本文件夹即可。
- 本目录内的大体积文件已写入 `.gitignore`，**不会进入 Git 版本库**（避免仓库膨胀、也避免泄露大文件）。
- 仅 `README.md`、`子目录/.gitkeep` 受版本控制，用于保留目录结构。
- 进入第二阶段时，会把需要的参考图**按需拷贝**到 `app/src/main/assets/` 或 `res/drawable/` 供运行时读取，不在此目录直接加载运行时资源。

## 建议结构
- `data/reference/`   参考地图 / 模板图（从夸克下载）
- `data/screenshots/` 后续截图匹配用的样本（第二阶段生成）
